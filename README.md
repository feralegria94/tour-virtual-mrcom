# Tour Virtual 360° — MR.COM Soluciones

Tour virtual interactivo con 5 escenas para visualización inmersiva de espacios.

**Demo:** https://feralegria94.github.io/tour-virtual-mrcom/

## Qué es

Aplicación web de tour virtual 360° construida con Pannellum.js. Permite navegar por espacios físicos con giros panorámicos y saltos entre escenas.

## Stack

- HTML5 / CSS3
- Pannellum.js (biblioteca de panorámicas 360°)
- JavaScript vanilla
- Imágenes equirectangulares optimizadas

## Características

- 5 escenas interactivas
- Navegación por puntos calientes
- Responsive: funciona en desktop y móvil
- Controles de zoom y rotación

## Estructura

```
├── index.html     # Punto de entrada
├── css/           # Estilos
├── js/            # Lógica de navegación
├── images/        # Escenas panorámicas
└── videos/        # Recursos multimedia
```
